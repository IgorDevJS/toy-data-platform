## Conclusão
Dois problemas na SQL API do Cube com o SQL que o Superset gera para o series_limit:
(a) ORDER BY por uma medida que não está no SELECT gera, para o Trino, SQL que referencia uma
    coluna inexistente ('catalog.title_key' cannot be resolved): erro visível;
(b) pior: um join com subconsulta de OUTRA medida roda, mas o Cube descarta o join em silêncio e
    devolve todos os gêneros (283 linhas). Com a mesma medida dentro e fora, o join é respeitado.
É o SQL que o Superset gera quando a métrica do gráfico (avg_rating) é diferente da métrica que
ordena as séries (count_catalog_titles). Decisão: lista fixa dos 10 gêneros (TOP_GENRES no bootstrap), aplicada
como filtro "genre IN (...)" nos dois gráficos de linha; a tabela calcula o top 10 pelo Cube e
confere a lista (3-07).
